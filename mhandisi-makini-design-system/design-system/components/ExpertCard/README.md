# ExpertCard
Profile summary of a professional: avatar, name, rating, trade, location, availability and “View profile”.

**Consumer provides:** `name`, `trade`, `rating` (+ optional `reviews`), `location`, `availability` (a StatusChip status), optional `avatarSrc` (initials show otherwise), `onViewProfile` or `href`, `elevated` for the featured shadow.

- White `mm-surface`, 1px `mm-border`, `mm-radius-md`, `mm-space-6` padding (`mm-space-4` on mobile).
- All six facts are required together — never let the star rating stand in for trust.
- Avatar illustrations follow the brand’s friendly style: charcoal outlines, yellow hard hats.
