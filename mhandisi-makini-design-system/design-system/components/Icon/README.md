# Icon
The built-in rounded 2px line icon set, drawn in `currentColor` on a 24px grid.

**Consumer provides:** `name`, optional `size` (default 20), `filled` (`true` = yellow fill for selected states, or a CSS colour), `label` when the icon carries meaning on its own.

- Decorative icons are `aria-hidden`; an icon-only control puts its `aria-label` on the control.
- Filled icons only for selected states (active nav) and the category motifs.
- No icon set was supplied with the brand; extend with a matching rounded 2px line set such as Lucide.
