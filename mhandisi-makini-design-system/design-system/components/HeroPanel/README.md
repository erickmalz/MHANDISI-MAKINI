# HeroPanel
The dashboard’s charcoal hero: large headline, one supporting line, search plus the yellow primary action, and a trust row.

**Consumer provides:** `title`, `subtitle`, `children` (usually a TextField and one primary Button), optional `trust` items (`{icon, label}`), and any illustration beside it.

- `mm-charcoal-900` panel, white text, `mm-radius-lg`, `mm-space-12` padding (`mm-space-6` on mobile); title in `display` (`display-mobile` below 768px).
- Exactly one yellow action. Illustrations: friendly worker/scaffold scenes, never hazard imagery or stock photos.
