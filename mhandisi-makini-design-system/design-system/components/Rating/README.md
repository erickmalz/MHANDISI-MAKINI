# Rating
A yellow star with the numeric score (and optional review count).

**Consumer provides:** `value` (0–5), optional `count`, `badge` for the tinted standalone badge.

- The star is `mm-yellow-500` and decorative; the number carries the meaning and the whole element has an `aria-label` (“Rated 4.9 out of 5”).
- Never convey trust through a rating alone — show it beside the trade, location and availability.
