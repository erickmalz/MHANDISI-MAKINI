# Logos
The supplied Mhandisi Makini logo files (hard hat over a gear with a check, wordmark, tagline “Let’s build together”), trimmed with clear space. Use as supplied — never redraw, recolour, stretch or add effects.

- `mhandisi-makini-horizontal-light.png` — charcoal + yellow on white. Headers, documents, light surfaces.
- `mhandisi-makini-stacked-light.png` — stacked version for square placements on light surfaces.
- `mhandisi-makini-horizontal-dark.png` — white + yellow on charcoal. Sidebar, dark headers, hero panels.
- `mhandisi-makini-stacked-dark.png` — stacked version on charcoal (app icon, splash, social).

Clear space = the height of the helmet brim. Never on busy imagery; never yellow text on white. The dark files carry their own charcoal ground (#292d30), a hair lighter than `mm-charcoal-900`.
