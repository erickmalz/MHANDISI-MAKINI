# Review before release

Run this before calling any MHANDISI MAKINI deliverable done. Report anything
that fails rather than shipping it quietly.

## Brand

- [ ] Spelling is exactly `MHANDISI MAKINI` (or `Mhandisi Makini` in prose).
- [ ] Approved logo variant for the background it sits on.
- [ ] Clear space ≥ 2X the hard-hat brim height on all four sides, measured
      from the artwork not the image canvas.
- [ ] Stacked logo ≥ 160 px on screen / 35 mm print; symbol ≥ 32 px / 10 mm.
- [ ] Logo not stretched, rotated, recoloured, shadowed or rearranged.
- [ ] Wordmark is the artwork, not retyped in a font.
- [ ] Tagline is "Let's build together", outside the clear space, smaller than
      the brand name — or omitted where it would be unreadable.
- [ ] Checkmark not used to imply inspection or approval.

## Colour

- [ ] Only Site Yellow, Charcoal, White, Concrete, Slate + the four status
      colours. No stray hexes.
- [ ] No white text on yellow (1.66:1). No yellow text on white (1.66:1).
- [ ] Roughly 70% white/pale, 20% charcoal, 10% yellow.
- [ ] Every status colour is paired with a readable word.
- [ ] Yellow marks the primary action, not warnings, not decoration.

## Typography

- [ ] One family throughout (DejaVu Sans, or the approved fallback).
- [ ] Sentence case headings, buttons and navigation.
- [ ] A clear reading order — not every line bold and oversized.
- [ ] Body 16 px at 1.5 line height (11 pt / 1.15–1.3 in print).
- [ ] No condensed type, no long italic passages, no all-caps paragraphs.

## Layout

- [ ] Spacing is on the 8 px scale (4 px only for micro adjustments).
- [ ] ≥ 24 px between major sections.
- [ ] 16 px mobile margins / 24–32 px on larger screens.
- [ ] Cards: 8 px radius, 16 px padding, subtle border.

## Interface

- [ ] One dominant action per view.
- [ ] Buttons name a specific verb and object.
- [ ] Every field has a persistent visible label; placeholders are not labels.
- [ ] Errors sit near their field and explain recovery.
- [ ] Touch targets ≥ 48 × 48 px.
- [ ] Visible keyboard focus on everything interactive.
- [ ] Active nav state indicated by more than colour.

## Copy

- [ ] Dates unambiguous (`06 Sep 2026`); units next to values.
- [ ] No success message before confirmation.
- [ ] No raw error codes as the only explanation.
- [ ] No unsupported claims about delays, safety or outcomes.
- [ ] Interface language consistent within each screen.
- [ ] Swahili text wraps fully; nothing essential is truncated.

## Assets and rights

- [ ] Image permissions obtained for people, projects and client information.
- [ ] Illustrative or staged material labelled where context could mislead.
- [ ] Claims match what the product actually does.
- [ ] Superseded assets archived so they can't be mistaken for current files.

## Real conditions

- [ ] Viewed at actual size.
- [ ] Contrast and focus checked on a real device in bright conditions.
